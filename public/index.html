A real engineering model, running live in a browser.

It started as a raw CAD design file. It was uploaded to Autodesk Platform Services, stored in the cloud, translated to a lightweight web format, and streamed right here — on a laptop, a phone, anywhere.

Durable storage, compute that scales on demand, and global low-latency delivery — all on AWS. That's the foundation Autodesk uses to serve millions of designs worldwide.

The pipeline behind this view

  1. Upload.stl / .step design file
  2. AuthenticateAPS OAuth 2.0 token
  3. Object Storage (OSS)durable cloud bucket → S3
  4. Model Derivativetranslate to SVF2 web format
  5. Stream to viewerCloudFront global delivery
♻️ Scale-to-zero storage
🌍 Low-latency worldwide
🔒 Secure by default

Ship the APS app to AWS — in plain English.

A developer describes the infrastructure they want. Kiro (Amazon's agentic IDE, powered by Bedrock/Claude) generates the infrastructure-as-code and deploys it. No hand-written YAML.
